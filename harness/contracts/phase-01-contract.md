## Checkable items

Every browser check runs in both Chromium and WebKit. Fixtures are in tests/fixtures/
(generated by `npm run fixtures`).

| # | Behavior | How to verify | Result (filled in at review) |
|---|---|---|---|
| 1 | "Open PDF" with `basic-3-pages.pdf` draws page 1: its canvas shows page 1's band color | e2e reads canvas pixels | |
| 2 | Scrolling to the bottom draws the last page (`basic-3-pages` and `long-300-pages`) | e2e: last slot reaches `rendered` and shows its band color | |
| 3 | On the 300-page book, scrolling top to bottom in steps never has more than 8 drawn canvases at once, and pages far from the viewport release their canvas | e2e counts `rendered` slots and canvas sizes at each step | |
| 4 | In `mixed-sizes.pdf`, each page slot's aspect ratio matches its PDF page within 1%, and the landscape page is wider than tall | e2e measures slots | |
| 5 | Choosing `not-a-pdf.pdf` shows the alert "This file isn't a readable PDF.", and a valid PDF still opens afterwards | e2e | |
| 6 | Opening a second book replaces the first: no slots from the old book remain, and the new page count is shown | e2e | |
| 7 | Resizing the window re-fits pages to the new width, and the page being read stays in view | e2e with `setViewportSize` | |
| 8 | Importing `pdfjs-dist` outside `src/engine` fails `npm run lint` | Negative check: add the import, run lint, revert | |
| 9 | Layout and visible-range logic is unit-tested: top, middle, bottom, overscan clamping, single page, empty layout | `npm run test:unit` | |
| 10 | `scripts/verify.sh` reports PASS | Run it | |
| 11 | User-checked: a real book opens in `npm run dev` and scrolls without visible problems | User tries it; recorded as user-observed | |

## Out of scope for this contract

- Speed budgets (02)
- Password-protected PDFs (they show the generic error)
- Drawing on an off-main-thread canvas (decided in phase 02)
