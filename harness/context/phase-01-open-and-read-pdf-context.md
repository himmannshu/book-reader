# Phase 01 context: open and read a PDF

Material decisions only.

## Engine interface (src/engine/types.ts)

- `PdfEngine.open(bytes) → PdfDoc`. `PdfDoc` exposes `pageCount`, `firstPageSize`,
  `loadPageSizes()`, `renderPage(index, canvas, scale) → { promise, cancel }`, `destroy()`,
  and `destroyed`.
- Errors: `PdfOpenError` (`invalid | password | unknown`), `RenderCancelledError`.
  PDF.js error classes never leave the adapter.
- Page indexes are 0-based everywhere outside the adapter. PDF.js's 1-based page numbers stay
  inside src/engine/pdfjs-engine.ts.
- Enforced by lint: only src/engine/** may import pdfjs-dist.

## Where the work happens (honest scope of "in a worker")

- PDF.js parses and decodes in its Web Worker. The final drawing onto each canvas runs on the
  main thread, as in PDF.js's standard setup.
- Revisit in phase 02. If page drawing blocks scrolling, try drawing off the main thread
  (OffscreenCanvas) or try PDFium behind the same interface (D3).

## Fast open: estimate, then correct

- The layout starts with every page assumed to match page 1, so page 1 draws immediately.
  `loadPageSizes()` then measures all pages in the background, and the layout is recomputed
  while keeping the reader's place (anchor = page index + fraction).
- Trade-off: on books with mixed page sizes, positions shift once, shortly after opening.
  Phase 02 measures whether this is visible on long books.

## Memory bounds

- At most 8 drawn pages at any time (`maxRenderedPages`), with overscan of 1 page on each side.
  A page leaving the range has its draw cancelled and its canvas shrunk to 0×0 and removed.
- Canvas resolution uses `devicePixelRatio` capped at 2.
- These numbers are starting points. Phase 02 turns them into measured budgets.

## Platform floor

- pdfjs-dist 6.4 uses `Promise.withResolvers`, so the minimum is Safari/iOS 17.4.
- PDF.js 6 moved `destroy()` from the document to its loading task. The adapter calls
  `doc.loadingTask.destroy()`.

## Test fixtures

- Generated by scripts/generate-fixtures.mjs (pdf-lib, fixed dates). Regenerating gives
  byte-identical files. Each page has a color band based on its index (`bandColor`, duplicated
  in e2e/helpers.ts), so tests can tell which page a canvas shows. tests/fixtures/manifest.json
  lists the page sizes.
