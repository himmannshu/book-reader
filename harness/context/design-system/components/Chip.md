# Chip

Filter toggles above the library shelf: All, Reading, Unread, Finished, In cloud.

- Several can sit in a row; `selected` shows a check and `accent` on `accent-soft`, so the state never relies on colour alone.
- `count` shows how many books match, in tabular figures.
- Not for actions. A chip that does something is a Button.

Consumer provides: `children`, `selected`, optional `count`, `icon`, `onClick`.
