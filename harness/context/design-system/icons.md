# Icons

- 47 stroke icons on a 24px grid, 1.75px stroke, round caps and joins. Paths from Lucide (ISC license), renamed to the reader's vocabulary.
- Single ink: every file is drawn in `ink` from the Light theme (#29241e). An `<img>` cannot recolour them, so in the app use the `Icon` component, which draws the same paths in `currentColor`.
- Sizes: 20px in toolbars and rows, 18px in buttons, 16px in chips and metadata.
- `contents` opens the table of contents, `text-settings` opens reading settings, `listen` starts read-aloud, `voice` marks a spoken note, `sepia` is the Sepia theme.
